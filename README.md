# prime-number-rating-system

## ランキング集計（画像読み取り） — `ranking-ocr.html`

素数あつめのランキング画面のスクリーンショットをまとめて読み取って、種目ごとの順位表と JSON を作るページです。
画像はどこにも送らず、ブラウザの中だけで読み取ります（外部の AI などは使いません）。

- 見出しの種目名を見分けて、22 種目（素数ゲーム 18 種目・スコアの合計 2 種・累積 2 種）に振り分けます
- コンパクト表示（各グループの左が 1〜10 位、右が 11〜20 位）と、ふつうの表示の両方を読めます
- タイムの 4 種目（1から順に・2から順に・1桁素数・2の累乗数）は「小さいほど上」として確かめます
- 順位と点数の並びがさかさまな所や、画像によって読みがちがう所は「checking!」に出て、その行へ飛べます
- JSON には読み取れた順位だけが入ります（間が抜けていても書き出せます。checking! が残った順位は入れません）
- data.json の週の形（borders / totalBorders / lsBorders）も いっしょに書き出します
- スクロールして見出しが半透明になった画像や、iPhone の上に出る丸いものが種目名に重なった画像でも、種目を見分けます
- 「さらに読み込む」ボタンは読みとばします
- 「あなたの順位」の欄は一覧より新しい値が出ることがあるので、順位表には混ぜずに「自分の順位」として別に出します
- 素数のスコアは緑の札（白い字）で出ます。札かどうかは「緑の中に白い字があるか」で見分けるので、札の行が多い画面（例：199・197 が続く所）でも読めます
- 300 枚以上でも軽く動くように、読み取り中の描き直しは端末の速さに合わせて間をあけます。
  画像一覧は「気になる画像だけ」がふだんの表示で、順位一覧は 300 行ずつ（「もっと見る」で続き）出します

## ランキング分析（だれでも見られます） — `ranking-analysis.html`

公開データ（`rankings/`）を自動で読み込んで、次のことを調べられるページです。
ランキング集計の JSON を自分で読み込むこともできます（同じ週は、自分の JSON が優先です）。

- 位置しらべ：記録から「何位くらい・上位何%・偏差値いくつ」と、総合偏差値・平均偏差値・得意な種目・偏差値のならび（グラフ）
- 偏差値の目安：種目ごとに、偏差値 60・70・80 に とどくのに要る記録と、だいたいの順位
- 種目のむずかしさ（200位に入るむずかしさ・1位と100位の差・100位あたりの1つの重さ・上位1%のすごさ）
- 順位と点数のグラフ（種目どうしを「1位を100%」にそろえて くらべられます）
- RATING への影響（同じ上位%でも、種目によって もらえる「すごさ」がどうちがうか）
- 週ごとの変化
- 偏差値の出し方（式の説明・つまみで動かせる つりがね形の図・見つもりの確かめ）

RATING（`index.html`）の「分析」タブにも、同じ計算の「偏差値（概算）」カードがあります（次の目標つき）。

## 成績表 — RATING の「成績表」タブ（ホームのすぐ下）

全統模試ふうの 個人成績表です。公開データ（`rankings/`）と、その端末の記録から作ります。

- 総合成績：十種競技総合スコア（素数判定を除く 9 種目）の 総合偏差値・得点・全国順位・受験者数・上位%・予測平均点・予測標準偏差・評価
  （予測平均点・予測標準偏差は、受験者 全員の得点を予測して並べた時の 平均と標準偏差です）
- 種目別成績（素数ゲーム 18 種目）と、やりこみ成績（生成した乱数の累積・スコアの累積）
- 偏差値グラフ（50 を まん中に、上は青・下は だいだい）、目標判定（総合の 1000位〜1位）、次の目標、計算の注
- 偏差値・予測平均点・予測標準偏差は 小数第2位まで、全国順位は いつも出します（見つもりの時は「約」）
- 評価：S 75以上 ／ A 65以上 ／ B 60以上 ／ C 55以上 ／ D 50以上 ／ E 50未満。判定：A 到達 ／ B 差 1 未満 ／ C 2.5 未満 ／ D 5 未満 ／ E 5 以上

## 偏差値（概算）の出し方 — `rank-model.js`（v3）

ランキングには全員の点数がのっていないので、ランキングに載っている所は「順位」から出します。

1. 上位の割合　`p ＝（順位 − 0.5）÷ 参加人数 N`（参加人数は、ゲームの画面の「◯位 / ◯ プレイヤー」から読み取った人数）
2. 標準正規分布で、上から p の所の値　`z ＝ Φ⁻¹(1 − p)`
3. `偏差値 ＝ 50 ＋ 10 × z`

ランキングに載っていない所は「予測分布」から出します。

- 記録 x を `y ＝ g(x)` に直して、y が つりがね形（正規分布）に ちらばる と考えます
  - 点数（素数ゲーム・スコアの合計）：`y ＝ x^(3/4)`／タイム：`y ＝ −√x`（速いほど大きい）／累積：`y ＝ x^0.3`
- 読めた いちばん下の順位 L から z の幅 0.4 の中の点で、y を z の直線で表した傾き σ（最小二乗）
  - 点数と累積は「最下位（N 位）の人は 0 くらい」とするので `σ ≥ y_L ÷（z_L − z_N）`
  - 点数は「まん中の人は 0 点より上」とするので `σ ≤ y_L ÷ z_L`（z_L ＞ 0 の時。累積は 深い順位が かえって当たらなくなるので入れません）
- 直線が L を通るように `μ ＝ y_L − σ z_L`
- `z ＝（y − μ）÷ σ`、全国順位 ≈ `N × Q(z) ＋ 0.5`（Q は上側確率）、`偏差値 ＝ 50 ＋ 10 × z`

予測平均点・予測標準偏差は、参加者 N 人の記録を 1位から N 位まで並べたもの `x̂₁ … x̂_N` の 平均と標準偏差です。

- `r ≤ r_L`：読めた記録（抜けている順位は y と z を まっすぐ結んだ値）
- `r ＞ r_L`：`x̂_r ＝ g⁻¹(μ ＋ σ z_r)`、`z_r ＝ Φ⁻¹(1 − (r − 0.5) ÷ N)`（`μ ＋ σ z_r` が 0 より下なら 0）
- `予測平均点 x̄ ＝ Σ x̂_r ÷ N`、`予測標準偏差 ＝ √(Σ (x̂_r − x̄)² ÷ N)`

べき（3/4・1/2・0.3）は、2026-11-01 の 1〜1000 位で「上位 200・300・500 位だけで当てはめて、その下の読めた順位を当てる」ことと、
一覧より下の記録（非公開）と、累積は 2026-10-31 に読めた 1480〜10000 位を当てることで ためして、いちばん よく当たったものです。
「参加者 全員の記録が そのまま正規分布」と考えて最尤推定するやり方（`fitNormalAll`）とも くらべていて、
2026-11-01 のデータで、上位 200 位から当てた時の偏差値のずれは 平均 1.12（全員が正規分布 は 2.63）、上位 500 位からは 0.35（同 0.79）でした
（全員が正規分布 と考えると、十種競技総合スコアなど 5 種目は 平均点 μ が マイナスになります）。
ランキング分析のページの「偏差値の出し方」で、同じ くらべを その週のデータで見られます。

- ◎：読めた順位で、順位がぴったり決まる所
- ○：読めた順位のあいだ（y と z を まっすぐ結んで見つもります）
- △：読めた順位より下（予測分布から出します）
- 参加人数が読めていない週は、前の週の人数を使います（`fillPlayers`。画面に「◯月◯日の人数」と出ます）

`rank-model.js` は RATING と分析ページの両方が読み込む、計算だけのファイルです（Node.js でも動きます）。

## 公開データ — `rankings/`

- `rankings/index.json`：公開している週の一覧（`latest` と `weeks: [{ date, file, categories, ranks }]`）
- `rankings/<日付>.json`：その週の全部の順位。種目ごとに `players`（参加人数）・`ranks`（順位 → 点数）・`extra`（一覧の外で読めた［順位, 点数］）
- 名前は入っていません（読み取っていません）。checking! が残った順位も入りません

## 使う流れ

1. `ranking-ocr.html` で、その週のスクリーンショットを全部読み取って、checking! を直します
2. 「JSON をダウンロード」で JSON を保存します
3. RATING の開発者メニュー →「集計の JSON を読み込む」で、その JSON を選びます（ボーダーの欄に入ります）
4. いつもどおり「GitHubに直接反映する」で data.json に反映します
5. 同じ所の「全部の順位を公開する」を押すと、`rankings/` に書きこまれて、偏差値と分析ページに使われます
   （画面の「あなたの順位」の欄は自分の記録なので、ふだんは入れません）

## 確かめる道具（Node.js だけで動きます）

```
node tools/ranking-ocr-dev.js test <画像フォルダ>   # 画像の読み取り
node tools/rank-model-test.js [週の JSON]          # 偏差値の計算と、上位 K 位からの当てくらべ（何も付けなければ rankings/ の いちばん新しい週）
```
