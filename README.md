# prime-number-rating-system

## ランキング集計（画像読み取り） — `ranking-ocr.html`

素数あつめのランキング画面のスクリーンショットをまとめて読み取って、種目ごとの順位表と JSON を作るページです。
画像はどこにも送らず、ブラウザの中だけで読み取ります（外部の AI などは使いません）。

- 見出しの種目名を見分けて、22 種目（素数ゲーム 18 種目・スコアの合計 2 種・累積 2 種）に振り分けます
- コンパクト表示（各グループの左が 1〜10 位、右が 11〜20 位）と、ふつうの表示の両方を読めます
- タイムの 4 種目（1から順に・2から順に・1桁素数・2の累乗数）は「小さいほど上」として確かめます
- 順位と点数の並びがさかさまな所や、画像によって読みがちがう所は「checking!」に出て、その行へ飛べます
- JSON には読み取れた順位だけが入ります（間が抜けていても書き出せます。checking! が残った順位は入れません）
- data.json の週の形（borders / totalBorders / lsBorders）も いっしょに書き出します
- スクロールして見出しが半透明になった画像や、iPhone の上に出る丸いものが種目名に重なった画像でも、種目を見分けます
- 「さらに読み込む」ボタンは読みとばします
- 「あなたの順位」の欄は一覧より新しい値が出ることがあるので、順位表には混ぜずに「自分の順位」として別に出します

## ランキング分析（だれでも見られます） — `ranking-analysis.html`

公開データ（`rankings/`）を自動で読み込んで、次のことを調べられるページです。
ランキング集計の JSON を自分で読み込むこともできます（同じ週は、自分の JSON が優先です）。

- 位置しらべ：記録から「何位くらい・上位何%・偏差値いくつ」と、総合偏差値・平均偏差値・得意な種目・偏差値のならび（グラフ）
- 偏差値の目安：種目ごとに、偏差値 60・70・80 に とどくのに要る記録と、だいたいの順位
- 種目のむずかしさ（200位に入るむずかしさ・1位と100位の差・100位あたりの1つの重さ・上位1%のすごさ）
- 順位と点数のグラフ（種目どうしを「1位を100%」にそろえて くらべられます）
- RATING への影響（同じ上位%でも、種目によって もらえる「すごさ」がどうちがうか）
- 週ごとの変化
- 偏差値の出し方（式の説明・つまみで動かせる つりがね形の図・見つもりの確かめ）

RATING（`index.html`）の「分析」タブにも、同じ計算の「偏差値（概算）」カードがあります（次の目標つき）。

## 偏差値（概算）の出し方 — `rank-model.js`

ランキングには全員の点数がのっていないので、平均と標準偏差のかわりに「順位」から出します。

1. 上位の割合　`p ＝（順位 − 0.5）÷ 参加人数`（参加人数は、ゲームの画面の「◯位 / ◯ プレイヤー」から読み取った人数）
2. 標準正規分布で、上から p の所の値　`z ＝ Φ⁻¹(1 − p)`
3. `偏差値 ＝ 50 ＋ 10 × z`

- ◎：読めた順位で、順位がぴったり決まる所
- ○：読めた順位のあいだ（点数と z を まっすぐ結んで見つもります）
- △：いちばん下の読めた順位より下（いちばん下の所の「点数と z の傾き」で延ばします）。延ばすのは z で 1〜1.5 ぶんまでで、その先は「◯位より下」とだけ出します
- 生成した乱数の累積・スコアの累積は「点数の対数」、タイムは「タイムの対数にマイナスを付けたもの」で同じように計算します
- 画面の「あなたの順位」の欄（一覧の外の点）があると、その点までは ○ で見つもれるので、ずっと確かになります

`rank-model.js` は RATING と分析ページの両方が読み込む、計算だけのファイルです（Node.js でも動きます）。

## 公開データ — `rankings/`

- `rankings/index.json`：公開している週の一覧（`latest` と `weeks: [{ date, file, categories, ranks }]`）
- `rankings/<日付>.json`：その週の全部の順位。種目ごとに `players`（参加人数）・`ranks`（順位 → 点数）・`extra`（一覧の外で読めた［順位, 点数］）
- 名前は入っていません（読み取っていません）。checking! が残った順位も入りません

## 使う流れ

1. `ranking-ocr.html` で、その週のスクリーンショットを全部読み取って、checking! を直します
2. 「JSON をダウンロード」で JSON を保存します
3. RATING の開発者メニュー →「集計の JSON を読み込む」で、その JSON を選びます（ボーダーの欄に入ります）
4. いつもどおり「GitHubに直接反映する」で data.json に反映します
5. 同じ所の「全部の順位を公開する」を押すと、`rankings/` に書きこまれて、偏差値と分析ページに使われます
   （「あなたの順位」の欄も入れるかどうかを えらべます）

## 確かめる道具（Node.js だけで動きます）

```
node tools/ranking-ocr-dev.js test <画像フォルダ>   # 画像の読み取り
node tools/rank-model-test.js [週の JSON]          # 偏差値の計算（何も付けなければ rankings/ の いちばん新しい週）
```
